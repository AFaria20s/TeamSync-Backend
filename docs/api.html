TeamSync API Documentation

Current REST API reference for the TeamSync backend. This page documents authentication, team-scoped resources, global resources, and request payload examples.

Base URL: http://localhost:8080 Auth: JWT Bearer Token Backend: Spring Boot

Authentication

TeamSync currently uses manager-based authentication. A manager logs in with email and password and receives a JWT token.

Authorization: Bearer <token>
Account creation is not publicly available yet. Registration is planned and already under development. The expected flow is to create the first Team and first Manager together, then return a JWT for the new manager.

GET/api/teamGet the authenticated manager's team.

Current API Notes

Authentication

Only /api/auth/** is public. Every other endpoint requires a valid JWT token.

Accounts

Authentication currently supports manager accounts only. Registration is planned and under development.

Team Scope

Team-owned resources derive the team from the authenticated manager, not from request bodies.

Global Resources

Disciplines, competitions, and addresses currently operate as global resources.
